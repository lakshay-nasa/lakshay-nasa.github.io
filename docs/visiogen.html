3D VisioGen: From 2D Images to 3D Models

Lakshay Nasa | September 2023

In my research endeavor, I dedicated myself in advancing the processing of visual data through the innovative approach of converting 2D images into intricate 3D models. Leveraging a combination of image processing techniques with Python programming and lightglue and using computer vision libraries as well as methodologies like SFM and Triangulation and TKf algorithm. My goal is to open new doors in spatial modeling applications ranging from automation and gaming to robotics, architecture and beyond. Plus, I'm seeing ways to integrate it with Machine Learning and AI, which I think will take this project "VisioGen" to the next level.
